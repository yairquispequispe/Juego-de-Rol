# El bosque misterioso

Una aventura de decisiones: explora el bosque, reúne objetos y busca una salida.

## Cómo jugar

1. Ejecuta el juego con `python main.py`.
2. En el menú principal, elige si quieres comenzar una aventura, continuar una
   partida guardada, consultar tus resultados o salir.
3. Durante la aventura, elige una opción para avanzar. Selecciona `0` para
   guardar tu progreso y volver al menú.

La partida se guarda en `aventura.db`, en la carpeta desde la que ejecutes el
juego. Si empiezas una aventura nueva teniendo progreso anterior, el juego te
pedirá confirmación.
